## Marketing Relationnel
## Gestion de réseau des clients et commissions via graphe ponderé

1. Contexte du projet

Ce projet s’inscrit dans le cadre du TP intitulé “Gestion de réseau de clients et commissions via graphes pondérés”.

L’objectif est de modéliser un système de marketing relationnel où :

- Un client peut recommander d’autres clients

- Il reçoit une commission sur leurs achats

- Il peut également recevoir des commissions indirectes

Le système est représenté par un graphe orienté pondéré :

Nœud : un client

Arête (A → B) : A recommande B

Poids : commission générée par B pour A
